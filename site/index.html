Light Table

An ambitious live-coding editor.
A second chance for an original idea.

Archived in 2022, Light Table connected code to immediate feedback. We're keeping its original ClojureScript foundation and repairing one real workflow first.

Verified
Original editor launches, opens a file, accepts edits and saves. Restricted JavaScript arithmetic shows 42, then 43 beside the code, tied to exact source hashes.
Still on the Bench
Language plugins, native menus and modern runtime support. This is a working proof, not a ready release.

FIX THE CODE. KEEP THE SOUL.

Less Disposable.
More Possibility.

Software doesn't have to disappear when its first chapter ends. Useful repairs can keep ideas alive without pretending the old problems never existed.

  1. 01

    Dig Carefully

    Read the source and reproduce the problem. Preserve the history, the license and the people behind it.

  2. 02

    Make It Work

    Repair a concrete path. Keep the fix small enough to test and honest enough to inspect.

  3. 03

    Show the Evidence

    Publish clear limits and reproducible checks. Contribute upstream where practical, with credit intact.
