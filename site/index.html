Light Table

An ambitious live-coding editor.
A second chance for an original idea.

Archived in 2022, Light Table connected code to immediate feedback. We're keeping its original ClojureScript foundation while recovering editor, project, language and live-view workflows.

Open the repair log ↓

The public testing release is being prepared.
No public program download yet.

✓ VERIFIED LOCAL CHECKPOINTS

More Than the First Calculation.

The original editor runs on Electron 44.5.1. Recorded checkpoints cover project/file workflows, save preservation, JavaScript imports and watches, scoped state-preserving live edits, local/external language REPLs and an Ollama assistant V1 baseline. The latest completed baseline has a 41-entry regression, fresh Vite 33/33 and live demo 5/5.

THE RESCUE MANUAL

A Little Care.
A Lot of Possibility.

Not every old thing needs replacing.
Sometimes it just needs someone to look closer.

  1. 01

    Dig Carefully

    Read the source. Reproduce the problem. Preserve the history, the license and the people behind it.

    FIRST, UNDERSTAND WHAT'S WORTH SAVING.
  2. 02

    Make It Work

    Repair a concrete path. Keep the fix small enough to test and honest enough to inspect.

    ONE USEFUL FIX BEATS A BIG PROMISE.
  3. 03

    Show the Evidence

    Publish clear limits and reproducible checks. Contribute upstream where practical, with credit intact.

    LEAVE A TRAIL SOMEONE ELSE CAN FOLLOW.
